# Nákupní seznam
## konzolová aplikace
Jednoduchá konzolová aplikace pro seznámení s Pythonem, pro zapsání nákupního seznamu, který se uloží do txt souboru.
## Funkce
- Přidávání položek do nákupního seznamu pomocí názvu a ceny
- Vypsání celého nákupního seznamu
- Vypsaní celkové ceny  nákupního seznamu

Nákup se ukládá do textového souboru.
## jak program spustit ?
Ke spuštění musí být nainstalovaný python 3. poté se dá program spustit double clickem, nebo v terminálu pomocí příkazu python nakup.py
## co jsem se naučil ?
Základní seznámení s Pythonem, práce se souborem read a write, práce s Python Dictionary
